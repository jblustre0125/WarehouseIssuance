# Pages

User-facing PHP pages are grouped here by role so future page work is easier to locate.
The root `index.php` redirects users into these pages after login.

- `pages/requestor` - `requestor.php`, `requestor_report.php`
- `pages/picker` - `picker.php`, `picker_report.php`
- `pages/issuer` - `issuer.php`, `issuer_scan_report.php`
- `pages/receiver` - `receiver.php`
- `pages/reports` - `requestor_report.php`, `issuer_scan_report.php`, `view_transactions.php`
- `pages/dashboard` - `verification_dashboard.php`
- `pages/admin` - `admin_users.php`
- `pages/auth` - `login.php`, `logout.php`
